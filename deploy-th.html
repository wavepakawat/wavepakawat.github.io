Deployment Guide

เอาเว็บขึ้น GitHub User Page

Repo: wavepakawat.github.io · เว็บจะอยู่ที่ https://wavepakawat.github.io

ข่าวดี: โปรเจกต์ตั้งค่าไว้ครบแล้ว — มี GitHub Actions workflow ที่ deploy ให้อัตโนมัติทุกครั้งที่ push ขึ้น main, ตั้ง base: "/" ถูกต้องสำหรับ user page, และ remote ก็ผูกไว้แล้ว เหลือแค่ 3 ขั้นตอนหลักด้านล่าง

1 เช็กว่ามี repo บน GitHub แล้ว

ต้องมี repository ชื่อ wavepakawat.github.io (ชื่อต้องตรงเป๊ะกับ username ของคุณ) และตั้งเป็น Public

  • ถ้ายังไม่มี: ไปที่ github.com/new → ตั้งชื่อ wavepakawat.github.io → เลือก Public → กด Create (ไม่ต้อง ติ๊ก add README)
  • ถ้ามีแล้ว ข้ามไปขั้นตอนที่ 2 ได้เลย

2 Push โค้ดขึ้น GitHub

เปิด Terminal ที่โฟลเดอร์โปรเจกต์ แล้วรันทีละบรรทัด:

git add -A
git commit -m "Deploy portfolio"
git push -u origin main

นี่เป็นการ push ครั้งแรก จึงใส่ -u origin main ครั้งต่อ ๆ ไปแค่ git push ก็พอ

ถ้า push ไม่ผ่าน เพราะถาม login: ใช้ Personal Access Token แทนรหัสผ่าน — สร้างที่ Settings → Developer settings → Tokens (เลือกสิทธิ์ repo) แล้วเอา token มาวางตอนถาม password

3 เปิด GitHub Pages (ครั้งเดียว)

เข้าไปที่ repo บนเว็บ GitHub แล้ว:

  • กดแท็บ Settings
  • เมนูซ้ายเลือก Pages
  • หัวข้อ Build and deployment → ช่อง Source เลือกเป็น GitHub Actions (ไม่ใช่ "Deploy from a branch")

ตั้งค่านี้ครั้งเดียวพอ ไม่ต้องทำซ้ำอีก

4 รอ build เสร็จ แล้วเปิดเว็บ

  • ไปที่แท็บ Actions ของ repo จะเห็น workflow "Deploy to GitHub Pages" กำลังรัน
  • รอจนขึ้นเครื่องหมายถูกสีเขียว (ปกติ 1–2 นาที)
  • เปิด https://wavepakawat.github.io 🎉

ครั้งแรกอาจขึ้น 404 อยู่ครู่หนึ่ง รออีก 1–2 นาทีแล้ว refresh

อัปเดตเว็บครั้งต่อไป

แก้โค้ดเสร็จ แค่ push เข้า main — Actions จะ build & deploy ให้เอง:

git add -A
git commit -m "Update content"
git push

แก้ปัญหาที่เจอบ่อย

  • เปิดแล้วเป็นหน้า 404 / README: ไปเช็ก Settings → Pages ว่า Source = GitHub Actions และดูแท็บ Actions ว่ารันเขียวแล้ว
  • เว็บโชว์แต่หน้าขาว / ไฟล์ CSS-JS โหลดไม่ขึ้น: เกิดจาก base path — โปรเจกต์นี้ตั้ง base: "/" ไว้ถูกแล้วสำหรับ user page ไม่ต้องแก้
  • Actions ขึ้นแดง (build fail): กดเข้าไปอ่าน log บรรทัดสีแดง มักเป็น error ตอน bun run build — แก้ที่เครื่องให้ bun run build ผ่านก่อนแล้วค่อย push ใหม่
  • repo เป็น Private: GitHub Pages ฟรีต้องเป็น Public (Settings → General → ล่างสุด เปลี่ยนเป็น Public)
